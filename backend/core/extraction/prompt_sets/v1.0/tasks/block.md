# Task: blocks and plan zones

The pages describe the plan's blocks or zones. Return one entry in blocks for every block or plan zone the pages state rules, a land use or planning notes for, keyed by its label as printed in block_ref.

- rules: only rules stated for the block as a whole; land_use is the planned land use of the block.
- area_m2: the block's area, when printed.
- notes: other statements about the block (general planning notes), one per statement, as printed.
- is_total_row is true only for a totals row of a table.
